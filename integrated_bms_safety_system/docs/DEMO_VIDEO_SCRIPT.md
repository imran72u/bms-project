# Demo Video Script — Integrated BMS Safety & IoT System

Target length: 6–8 minutes.

1. Introduction — show the single Wokwi project and state that six internship tasks are integrated.
2. Architecture — show the architecture and workflow diagrams.
3. Normal operation — run Wokwi, adjust cells slightly, show LCD and dashboard.
4. Cell imbalance — change one cell and show weakest/strongest, imbalance, threshold and trend.
5. Protection + fault — raise current above the trip point or press FAULT; show relay and fault state.
6. Sensor anomaly — demonstrate frozen or unrealistic input.
7. Network outage — show queue growth, restore connectivity, then show REPLAY and queue drain.
8. Recovery — clear fault and show bounded recovery toward DEGRADED/NORMAL.
9. Final — show GitHub structure, Wokwi project and dashboard.
